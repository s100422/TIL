# 어려웠던 점
---
* 처음에 claude - vercel - supabase 를 연동하는 과정이 AI에게 다 맡겼음에도 좀 복잡하게 느껴졌다. 아직 흐름을 제대로 파악하지 못해서 그런 것 같다.
>claude 에서 Github로 `푸쉬` 및 `커밋`하여 Github repo 로 넣으면 그걸 연동해 놓은 vercel로 배포, data가 `c`,`r`, `u`, `d` 가 되면 supabase가 연동되면 배포해 놓은 페이지도 업데이트 된다.
# 느낀 점
---
기획하는 것에 두 시간을 썼는 데 그래서 기획 단계가 가장 힘들었다. 하지만 기획을 제대로 잡고 가니 AI를 이용한 실제 제작 과정은 순조로웠다. 다른 분들이 이미지 에셋을 잘 활용하는 것을 보고 나도 조금씩 이미지 에셋을 미리 만들어 놓기 시작했다. 그렇게하니 이전 실습보다 더 내가 생각했던 대로 나왔다.
