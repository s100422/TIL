# 고군분투 개발 체크포인트

각 체크포인트는 **브라우저에서 눈으로 확인 가능한 결과물** 단위로 나뉘어 있다.
완료 시 `[x]`로 체크한다.

## Phase 1 — 핵심 스윙 물리 프로토타입

- [x] **CP1. 빈 캔버스 화면 띄우기**
  `index.html` + `css/style.css` + `main.js`/`canvas.js` 최소 연결. 브라우저에서 캔버스가 화면 전체에 뜨는 것 확인.
- [x] **CP2. 캐릭터(도형) 화면에 표시**
  `player.js` + `renderer.js`로 캐릭터를 도형으로 캔버스 위에 고정 표시.
- [x] **CP3. 중력으로 캐릭터가 떨어져서 바닥에 착지**
  바닥 지형 하나 + 중력 가속도 낙하 + 착지 정지. `collision.js` 최소 버전.
- [x] **CP4. 클릭하면 캐릭터가 점프**
  `input.js` 클릭 감지 + 고정 점프 벡터. 항상 같은 궤적으로 점프→착지.
- [x] **CP5. 공중에서 마우스 각도로 조준선 표시**
  공중 상태일 때 커서 위치에 따라 조준 방향선이 실시간 회전 (발사는 아직 없음).
- [x] **CP6. 앵커(탑) 화면에 배치**
  `anchor.js`로 와이어 부착 지점을 도형으로 표시.
- [x] **CP7. 공중에서 클릭 시 와이어 발사되어 앵커 명중**
  `wire.js` 레이캐스트. 조준 방향으로 선이 뻗어 앵커 명중 시 표시 변화.
- [x] **CP8. 와이어 명중 시 앵커 중심으로 진자 스윙**
  `AIR_WIRED` 상태. 앵커를 중심축으로 원운동하며 매달려 도는 것 확인.
- [x] **CP9. 마우스 떼면 관성으로 튕겨나감**
  릴리즈 시 접선 속도 계산 → `AIR_FREE`로 포물선 비행. **핵심 스윙 루프 완성.**
- [x] **CP10. 스윙 손맛 파라미터 튜닝**
  `SWING_GRAVITY_SCALE`로 스윙 속도를 낙하와 분리. 플레이 확인 후 **1.8** 확정.
  개발용 튜닝 패널(`devtools.js`)로 언제든 재조정 가능.

## Phase 2 — 상태 전환과 실패 처리

- [x] **CP11. 앵커 여러 개로 연속 스윙 체인**
  앵커 2~3개 배치, 비행 중 재클릭+조준으로 연속 매달리기.
- [x] **CP12. 낭떠러지 표시 및 낙하 감지**
  지붕 사이 낭떠러지 시각화 + 낙하 상태 감지.
- [x] **CP13. 낙하 시 재시도 팝업 표시 및 분기**
  정지 + "재시도?" 팝업. 재시도→스테이지 재시작 / 거부→타이틀 화면.
- [x] **CP14. 타이틀 화면과 게임 시작 버튼**
  "게임 시작" 버튼 첫 화면 + 전체 화면 전환 흐름 확인.

## Phase 3 — 스테이지 시스템

- [x] **CP15. 스테이지 데이터 기반 지형 배치**
  `stage.js`로 지붕/낭떠러지/앵커/G지점을 데이터로 정의·로드.
- [x] **CP16. G지점 도달 시 스테이지 클리어**
  목표 지점 도달 감지 + 클리어 연출. 스테이지 1 완주 확인.

## Phase 4 — 동전과 속도

- [x] **CP17. 동전 배치 및 획득**
  `coin.js`로 동전 배치, 접촉 시 획득 + 점수 상승.
- [x] **CP18. 퍼펙트 보너스 확인**
  한 구간 동전 전부 획득 시 보너스 지급. 하나 빼먹으면 미지급도 확인.
- [x] **CP19. 오토런 스크롤 적용**
  `camera.js`로 캐릭터 항상 자동 전진, 가만히 있어도 스크롤.
- [x] **CP20. 스테이지별 속도 증가 체감**
  스테이지 번호에 따라 속도 상승. 1단계와 비교 플레이로 체감.
- [x] **CP21. 점수/스테이지 HUD 표시**
  `ui.js`로 점수·스테이지·동전 수 실시간 표시.

## Phase 5 — 콘텐츠와 다듬기

- [x] **CP22. 스테이지 2~6 실제 플레이 가능**
  나머지 스테이지 제작, 1→6 연속 플레이 및 클리어 확인.
  **개정**: 사용자 요청으로 스테이지별 팝업/재시작 구조를 폐기하고, 6개 챕터 + 휴식 구간을
  하나로 이어붙인 **단일 코스**로 재구성. 추락 시 항상 코스 처음부터, 클리어는 완주 시 1회만.
  **개정 2**: 휴식 구간을 3배(420→1260px 상당)로 늘리고, 각 휴식 구간 중간에 와이어 없이
  순수 점프만으로 건너는 점프갭(80px)을 추가. 처음엔 130px로 뒀다가 타이밍 허용폭이
  50px밖에 안 나와 실패하는 걸 발견 → 80px로 줄여 허용폭 100px로 확보.
- [x] **CP23. 비주얼 스타일 적용 후 화면 비교**
  도형 placeholder를 확정 비주얼로 교체. 컨셉: 캐릭터=평범한 사람, 지붕=건물 옥상,
  탑=전봇대, 배경=서울 밤 스카이라인(남산타워 고정 랜드마크 + 반짝이는 별 + 패럴랙스).
  **개정**: 전경 건물/전봇대가 밑동 없이 공중에 뜬 것처럼 보이는 문제를 낭떠러지 색과
  이어지는 그라데이션으로 해결. **개정 2**: 배경 스카이라인/남산 언덕도 같은 문제(옥상 높이까지
  안 내려와서 빈 하늘 틈이 보임)가 있어, 배경 밑단 기준선(SKYLINE_BASE_Y·언덕 밑단)을 300/345에서
  옥상 높이(440)로 내려 전경과 바로 이어지게 수정.
- [x] **CP24. 사운드 효과 재생 확인**
  `audio.js` 추가 — 외부 음원 파일 없이 Web Audio API 오실레이터로 직접 합성(다른 비주얼이
  전부 Canvas 도형인 것과 같은 원칙). 와이어 발사(슝)/부착(딸깍), 동전 획득(은/금 다른 음),
  퍼펙트 보너스(아르페지오), 추락(하강음), 전체 클리어(4음 팡파르) 총 6종.
  첫 클릭에서 AudioContext 잠금 해제. 재생 여부는 오실레이터 주파수를 가로채는 계측으로
  각 트리거(발사/부착/동전/퍼펙트/추락/클리어)마다 의도한 소리가 정확히 나가는 것을 확인.
- [x] **CP25. 전체 플레이테스트 및 밸런스 조정**
  사용자 요청으로 `config.js`의 `GRAVITY`를 1400→2200, 개발용 `SPEED_SCALE_PREVIEW`를 1→1.5로
  확정 패치. 중력이 오르면서 지상 점프 최고 높이(151→96px)와 스윙 진자의 실질 세기
  (`SWING_GRAVITY_SCALE`가 곱해지는 기준값)도 함께 세졌고, 코스 속도는 진행 배율(1.0~1.6배)
  위에 1.5배가 추가로 곱해져 전체적으로 훨씬 빠르고 무거운 손맛이 됐다.
  자동 플레이 봇(`window.__dev` + 실제 마우스 이벤트 디스패치, 지상 점프는 지붕 끝
  25px 전에서 클릭, 공중에서는 사거리 내 가장 가까운 탑을 조준해 즉시 발사, 스윙은
  각속도가 정점 대비 일정 비율(≈80%)로 줄어드는 하강 구간에서 릴리즈)로 코스 전체를 검증.
  **결과**: 처음 5개 챕터 + 휴식 구간은 새 물리에서도 안정적으로 통과(점수 1000점 이상 누적).
  **남은 위험 구간**: 챕터 6의 마지막 4연속 체인(가장 빠른 속도 구간, 원래도 가장 어려운
  설계 의도)에서 릴리즈 비율/점프 타이밍을 여러 조합으로 바꿔봐도 매번 거의 같은 지점
  (x≈12170, 두 번째~세 번째 탑 사이)에서 실패 — 봇 전략의 한계일 수도 있으나, 사람이 직접
  플레이해서 이 구간만 별도로 확인해볼 필요가 있음(REPORT 참고).

- [x] **CP26. 레퍼런스 기반 네온 루프탑 아트 리디자인**
  제공된 레퍼런스의 보랏빛 밤하늘·청록 도시·붉은 기와 건물·따뜻한 창문 조명을 새 팔레트로
  재구성. 배경/심연/지붕/앵커/와이어/캐릭터/HUD/버튼을 한 스타일로 통일하되, 물리와 코스 데이터는 변경하지 않음.
