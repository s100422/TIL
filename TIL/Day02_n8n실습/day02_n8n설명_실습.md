### n8n workflow

![n8n.png](attachment:0adcd727-3020-45c0-8d26-4d5fdba2d23a:n8n.png)

1. 폼 입력으로 시트가 추가되는 트리거 발생
2. edit fields 에서 각 시트의 공통 필드인 email을 target_email로 연결
3. target_email과 일치하는 행을 각 시트에서 검색
4. Merge 로 나온 행을 합하기
5. IF문을 이용하여 각 폼의 답변들이 누락 없이 잘 들어왔는지 확인
6. 메일 중복 발송 방지를 위한 ‘발송 완료 이메일’ 시트 작성 후 그 시트에서 target_email이 있는지 확인
7. if1로 기록이 있는지 없는지 확인하여 보낸 기록이 없으면 Send a message 로 보냄
8. 보낸 기록이 없는 것은 메일 전송 후 Append row를 통해 ‘발송 완료 이메일 시트’에 추가
