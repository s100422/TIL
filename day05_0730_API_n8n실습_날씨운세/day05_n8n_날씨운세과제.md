# 4. 막혔던 지점과 해결 방법
날씨 정보를 split 하고 그 정보와 운세 결과 정리한 것이 edit field 에서 잘 합쳐지지 않았다. claud에게 물어보니
```
`Split Out`(날씨)과 `사주 결과 정리`(운세)가 **`Edit Fields1`의 같은 입력에 둘 다** 연결돼 있습니다. n8n은 이걸 "합쳐서 하나의 item"으로 만들어주지 않습니다. 들어오는 연결마다 노드를 **따로 실행**합니다.

그래서 지금 흐르는 item에는 `summary`만 있고 `result`는 아예 없습니다(그 반대 실행에서는 `result`만 있고 `summary`가 없음). 한 item에 두 필드가 같이 존재한 적이 없는 겁니다.
```
이렇다고 해서 Merge 노드를 추가하여 합쳐서 필드 표현식을 명시적으로 바꾸었더니 해결되었다.
```
{{ $('날씨 요약').first().json.summary }}
{{ $('운세 결과 정리').first().json.result }}
```
